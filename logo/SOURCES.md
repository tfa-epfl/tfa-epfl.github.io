# TFA logo

`TFA_Bull.svg` is an unchanged copy of the user-provided
`TFA_Bull_Original_Green_Vector.svg`, supplied on 2026-11-09.

The SVG preserves the original green (#005C41) and transparent background.
Shared CSS renders the logo in white on a transparent background in dark mode
and in the dark page footers, while keeping the original green in light mode.
It is used for the site headers, footers, and Links page.

The root `favicon.svg` centers the same artwork on a square white background
so the dark green stays visible on both light and dark browser surfaces.
It is rendered into `favicon.png` (96 x 96) and `favicon.ico`
(16, 32, 48, 64, 128, and 256 pixels). All pages declare the PNG at the stable
`/favicon.png` URL for browsers and Google Search; the ICO provides the
conventional `/favicon.ico` fallback. The SVG is retained as the vector source.
